### 3、配置服务器开发环境

#### 步骤1：按照CANN安装说明安装CANN

- <font color="red">**SS928V100拥有两个图像引擎，它们除却使用的CANN不一样，环境、步骤等都一致；在这里我们称呼SS928V100 SVP_NPU和SS928V100 NPU用于区分它们，请根据需求安装CANN。**</font>
- 在Ubuntu终端执行如下命令，安装Debian软件包。

```shell
sudo apt-get install -y gcc g++ cmake make unzip build-essential zlib1g-dev libbz2-dev libsqlite3-dev libssl-dev libxslt1-dev libffi-dev wget
```

![image-20250709110556955](./pic/image-20250709110556955-1752133704664-1.png)

- 在Ubuntu终端执行下面命令，使用wget工具下载Python 3.7.5源码包。

```shell
wget https://www.python.org/ftp/python/3.7.5/Python-3.7.5.tgz
```

<img src="./pic/image-20250709112145937-1752133704664-2.png" alt="image-20250709112145937" style="zoom:50%;" />

- 下载成功后，在Ubuntu终端执行下面命令，解压源码包。

```shell
tar -zxvf Python-3.7.5.tgz
```

- 在Ubuntu执行下面命令，进入到源码目录中，配置、编译和安装Python 3.7.5。

```shell
#进入源码目录
cd Python-3.7.5

#配置
./configure --prefix=/usr/local/python3.7.5 --enable-loadable-sqlite-extensions --enable-shared

#编译
make

#安装
sudo make install
```

- 安装成功后如下图。

<img src="./pic/image-20250709112756895-1752133704665-3.png" alt="image-20250709112756895" style="zoom:50%;" />

- 在Ubuntu终端执行下面命令，打开.bashrc文件。

```shell
vi ~/.bashrc
```

- 在文件末尾添加Python 3.7.5的环境变量，并保存退出。

```shell
export LD_LIBRARY_PATH=/usr/local/python3.7.5/lib:$LD_LIBRARY_PATH
export PATH=/usr/local/python3.7.5/bin:$PATH
```

<img src="./pic/image-20250709114027844-1752133704665-4.png" alt="image-20250709114027844" style="zoom:67%;" />

- 在Ubuntu终端执行下面命令，使环境生效并查看python、pip版本。

```shell
#环境生效
source ~/.bashrc

#查看python、pip版本
python3 --version
pip3 --version
```

<img src="./pic/image-20250709115107647-1752133704665-5.png" alt="image-20250709115107647"  />

- 在Ubuntu终端执行下面命令，更新pip，避免pip版本过低导致安装失败。

```shell
pip3 install --upgrade pip --user
```

<img src="./pic/image-20250709141743383-1752133704665-6.png" alt="image-20250709141743383" style="zoom:67%;" />

- 在Ubuntu终端执行下面命令，安装python软件包。

```shell
pip3 install wheel protobuf==3.13.0 psutil==5.7.0 numpy>=1.13.3 scipy==1.4.1 decorator==4.4.0 sympy==1.5.1 cffi==1.12.3 pyyaml pathlib2 --user
```

<img src="./pic/image-20250709145157089-1752133704665-7.png" alt="image-20250709145157089" style="zoom:67%;" />

- SS928V100 SVP_NPU和SS928V100 NPU分别对应的CANN软件包为`Ascend-cann-toolkit_6.10.t01spc030b270_linux.x86_64.run`和`Ascend-cann-toolkit_5.20.t6.2.b060_linux-x86_64.run`；**本文展示的是SS928V100 SVP_NPU对应CANN的安装，如果需要安装SS928V100 NPU对应的CANN，更换CANN软件包后按照步骤安装即可**。
- 将CANN软件包拷贝到Ubuntu中，在软件包所在路径的终端执行以下命令，安装CANN。

```shell
#赋予CANN软件包执行权限
chmod +x *.run

#安装CANN软件，请替换以下变量：
#	<path>：CANN指定安装目录
./*.run --install --install-path=<path>
```

#### 步骤2：搭建交叉编译环境

* SS928V100使用的交叉编译器为`aarch64-mix210-linux`，压缩包名称为`aarch64-mix210-linux.tgz`。

- 将交叉编译器压缩包拷贝至Ubuntu中，在压缩包所在路径的终端执行以下命令，安装交叉编译器。

```shell
#解压并切换目录

```shell
export PATH="/opt/linux/x86-arm/aarch64-mix210-linux/bin:$PATH"

* 可以看到一个enp0s9，这个就是和开发板桥接的网络。

```
cd /etc/netplan
vim 01-network-manager-all.yaml
```

* 写入内容如下

```
network:
  version: 2
  renderer: NetworkManager
  ethernets:
    enp0s9:
      addresses: [192.168.2.3/24]
      dhcp4: no
```

#### 步骤5：更新板端环境

**在开发板中执行**

* ```
  vi /etc/init.d/rcS
  ```

  在末尾加上如下内容：

  ```
  ifconfig eth0 down
  ifconfig eth0 192.168.2.88 netmask 255.255.255.0
  route add default gw 192.168.2.3
  ifconfig eth0 up
  mount -t nfs -o nolock 192.168.2.3:/home/hispark/shared /mnt
  ```

  其中/home/hispark/shared为服务器放置modelzoo代码的位置

  重启开发板

#### 步骤6：ping一下开发板和服务器，正常ping通

#### 步骤7：配置开发板SSH

配置完后，设置ssh密钥

注意开发板上sshd_config配置，AuthorizedKeysFile注意路径配置正确

```
StrictModes no
PubkeyAuthentication yes
PermitRootLogin yes 
AuthorizedKeysFile      ~/.ssh/authorized_keys
```

在服务器上执行

```
ssh-keygen -p -f ~/.ssh/id_rsa
ssh-copy-id -i ~/.ssh/id_rsa.pub root@192.168.2.88
ssh root@192.168.2.88
```

此时应该不需要密码
